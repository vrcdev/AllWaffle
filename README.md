# AllWaffle
Universal waffle dispatcher — detects the game and loads the right waffle.
```lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/vrcdev/AllWaffle/main/loader.luau"))()
```
Supported: Frontlines, Rivals, Operations: Siege, Hood Customs, Criminality, Reloaded Guns, Phantom Forces, Valoblox. New games get added to manifest.json — no loader changes needed.
